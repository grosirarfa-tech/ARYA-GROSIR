Pengaturan Sinkronisasi Apps Script

Panduan Setup Apps Script:

  1. Buka Google Sheets Anda, buat Sheet sesuai daftar struktur kolom.
  2. Klik menu Ekstensi > Apps Script.
  3. Salin Kode GAS yang disediakan di bawah ini ke editor script.
  4. Klik Deploy > New Deployment, pilih Type: Web App.
  5. Atur "Who has access" ke Anyone. Klik Deploy dan Salin URL Web App-nya ke form di atas.
